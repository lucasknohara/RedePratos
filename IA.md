## 1. Como a IA foi utilizada

A equipe utilizou o ChatGPT na organização, copiloto e esclarecimento de requisitos de entrega das disciplinas.

A IA foi utilizada como apoio, não como substituta das decisões ou do trabalho dos integrantes, os exemplos de solicitações abaixo são resumos representativos das interações, não transcrições literais.

## 2. Exemplos de solicitações e aplicação

| “Me guia na mudança do css base do meu projeto a o Tailwind.” | Apoio à refatoração do css para o Tailwind |
| “Leie esse PDF e me explique os requisitos pedidos pelas disciplinas nas entregas.” | Explicação e orientação sobre o solicitado. |
| “Quais verificações devo executar antes de concluir o Front-end?” | Organização da validação com lint, build e testes manuais no navegador. |
| “Me ajude a melhorar textos.” | Apoio na elaboração dos textos do sistema Redepratos, deste arquivo e README. |

## 3. Validação pela equipe

As sugestões não foram aceitas automaticamente. A equipe revisou as alterações, aplicou-as no repositório e verificou o resultado no navegador. Na auditoria do Front-end, a equipe informou os seguintes resultados:

- `npm run lint`: executado sem erros ou avisos no terminal.
- `npm run build`: compilação concluída com sucesso pelo Vite
- Navegação e responsividade: páginas testadas em desktop, tablet e celular, sem problemas relatados.
- Funcionalidades locais: formulários, filtros, solicitações, edição de perfil e demais interações do protótipo testadas manualmente.

## 4. Limitações e reflexão crítica

A IA pode sugerir código incompatível com o projeto, conter erros ou propor soluções mais complexas do que o necessário. Por isso, foi importante fornecer trechos atualizados, revisar as respostas, adaptar as sugestões e testar cada alteração. A equipe deve compreender o código utilizado e ser capaz de explicar suas decisões.

O uso do ChatGPT ajudou a organizar o trabalho e esclarecer questões técnicas, mas a responsabilidade pelo projeto, pelas decisões, pela validação e pela entrega permanece com os integrantes.
